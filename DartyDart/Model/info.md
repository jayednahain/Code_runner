## Understand the Basics
```dart
class User {
  final String name;
  final int age;

  User({required this.name, required this.age});
}

```

## Why Models Are  ?
Without models, you would work with raw JSON or data directly, which can lead to messy and error-prone code. Models provide structure and make your code easier to maintain.
